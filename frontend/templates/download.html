Export a search result

Use the search filters and choose CSV or FASTA. Current result CSV contains one row per matching peptide and condition class, 75 columns: 69 public summary fields, condition_class, split_group_id, and four coverage fields: selected_unit, unit_row_present, has_ug, has_uM. When the selected unit has no source row, identity fields remain available and measurement fields are empty; unit_row_present=false distinguishes this state. MIC organism/range filters retain only class rows that satisfy the filter. Search totals count peptides; CSV totals count class rows. FASTA omits NR and empty sequences.

Search parameters

Core search pages, core peptide API and filtered exports share these filters. corpus=publisher_literature and corpus=extended_literature select the two literature extraction sets. Both contain TIGER's own semantic reading and information extraction from publications. Archive and relationship endpoints use their separately documented scopes. Multiple complexity or terminus values may be repeated or comma-separated; categories are OR within one field and AND across fields.

Missing records return 404. Invalid parameters return 422 with an error message; request validation may also include detail. Source values remain strings where reported, including NR, empty strings and censoring symbols.

Vocabulary scope

complexity, termini, species, toxicity and condition_class return filter vocabularies. The extraction fields sequence_availability, endpoint_final, value_semantics, concentration_interpretation and host_whitelist_status return distinct source values, marked semantics=source_values_unharmonized. V2 covers both literature sets by default; add corpus to select one set. The response reports its scope.

Compatibility for existing scripts

The input aliases corpus=9pubs and corpus=DBAASP continue to select publisher_literature and extended_literature. The old DBAASP code identifies the literature-discovery cohort; its records now come from TIGER's own extraction. V2 responses and the entity CSV use the new names. V1 responses retain the legacy corpus codes.

V1 peptide detail retains historical single-row activity_cells and also provides current condition_summaries. Use v2 activity_cells for condition-class analysis. V1 extraction vocabularies default to the extended literature set; v2 defaults to both sets.

/download/source/{ug|uM} retains the legacy single-row aggregation with 69 public columns. Its response identifies legacy_single_row_summary and links to the current condition-class download. /download/core/{ug|uM} serves the detailed source-condition wide tables. All public table downloads expose literature-reported SMILES only, including compatibility routes; the release dataset cards above provide the current analysis summaries.

/api/v1/stats preserves legacy counters. In v2 stats, scope_notes defines those counters and current_collection supplies current archive counts. In particular, chemstruct includes retired structure records; use /api/v2/collection for active archive coverage.
