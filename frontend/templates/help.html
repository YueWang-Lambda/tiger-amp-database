How records are organized

AI agents extract peptide identities, molecular descriptions and measurements from original papers and supplementary material. The archive preserves entity records; core tables organize qualifying concentrations; relationship tables connect activity and toxicity through the same peptide.

Study activity and toxicity together

Open connected evidence to find peptides with activity and toxicity measurements, or use core search to combine molecular and concentration filters. Follow each evidence link to inspect endpoints, units and assay context.

Each connected-evidence row joins one peptide entity, one strain relation and one host relation. The links describe co-reported evidence, not precomputed therapeutic-index estimates. For a ratio-based analysis, define the antimicrobial and toxicity endpoints, use compatible concentration units, assess assay comparability and carry censored bounds through the calculation. The underlying measurements retain their own conditions.

For modelling, apply the condition-summary and training rules below. Count each source toxicity observation once when it is repeated across condition rows.

How entities enter the core tables

  1. Start with entities in included article packages and their activity and safety records.
  2. Apply source inclusion flags and supported endpoint, target and host rules: 14 microorganism categories and 9 safety host categories.
  3. Check concentration semantics, representable values and bounds, and explicit unit handling. Additional observations remain available with their source evidence.
  4. Retain entities with qualifying activity or toxicity concentrations and take the union of the µg/mL and µM memberships.

Activity, toxicity, or both can qualify an entity. Sequence availability and model-training eligibility are separate attributes.

Generator and unit-membership details

The generator empties a package's core rows when every cleaned sequence is an empty string; NR and empty strings are distinct. This package-level check allows individual sequence-missing entities in a package containing other sequences. See unit coverage for table membership and available values.

Original records and selected evidence

The current entity archive links 346,095 original measurement rows and 36,218 original safety rows. Restricting those source rows to core members gives 313,005 and 32,250, respectively. Ordinary MIC labels occur on 262,477 archive measurement rows, including 245,839 from core members.

Source rows preserve reported endpoints, point values, bounds, intervals, fixed-dose responses and other value states. Concentration summaries and resolved relationships apply additional endpoint, target, unit and value criteria. Repeated experiments can support one relationship; one source observation can contribute to multiple strain–peptide–host combinations through its peptide.

Cross-database comparisons also distinguish individual source rows from entries with text annotations or functional tags. The source-record audit reports each counting unit, and its shared-rule table counts deduplicated concentration signatures. A signature combines entity, target or host with reported strain and phenotype labels, endpoint, native unit, operator and value; repeated source rows can share a signature.

Source-quality review and unit handling

The source audit identified 258 safety rows with a comparison operator in the unit field. These retain their source values in the frozen archive and are outside the shared-rule concentration-signature subset. Corrections require source-evidence review; a value is not assigned a concentration unit from the operator alone. The audit revision changes comparison methods and documentation while retaining the released scientific tables.

Experimental relationship counts

Relationships use source observations for current core entities with core_eligible=yes, qualifying endpoints and targets/hosts, resolved concentration units, and positive exact values or censored bounds. Intervals, unresolved values, fixed-dose percentages and qualitative observations appear in the exclusion audit.

Peptide–strain activity relation
One entity ID and one species/explicit strain identity, supported by qualifying MIC/MBC-family measurements. Repeated conditions and endpoints contribute supporting measurements to the same relation. This release contains {{ collection.activity_bacterial_relations|number }} bacterial and {{ collection.activity_fungal_relations|number }} fungal relations.
Target and strain identity
Full species names and explicit abbreviations share the same supported category. Strain-label normalization covers whitespace, case, ATCC spacing and redundant resistance descriptions; other genetic annotations remain distinct. Explicit Shigella species retain separate strain identities within the genus-level category. Group, panel, pooled, unspecified and phenotype-only records retain their resolution states. Individual strain assignments require an unambiguous source table or figure. Detailed fields are strain_state, resolved_strain_key and target_identity_version.
Peptide–host toxicity relation
One entity ID and a supported cell line or erythrocyte source, with qualifying HC50/IC50/CC50 or explicitly contextualized hemolysis EC50 evidence. HEK293 and HEK293T remain distinct; human and mouse erythrocytes are different hosts.

MIC condition classes and training summaries

The 20 fixed classes comprise standard, modified and unspecified variants of MHB, LB, TSB, BHI and NB, plus DEFINED, SERUM-based, OTHER-reported, UNKNOWN and CONFLICT. A standard label describes explicit basal-medium evidence. Named basal CAMHB is included, with cation adjustment recorded separately; a bare medium name remains unspecified. Inoculum, incubation, temperature and other protocol details have separate fields.

Assay records preserve supplements, inoculum, pH, temperature, incubation and measurement notes. Classification uses measurement-level evidence; ambiguous multi-condition descriptions receive CONFLICT.

A wide summary row represents one peptide and one condition class, keyed by peptide ID plus class within a unit dataset. The long summary additionally distinguishes species and endpoint. Keep the same split_group_id in one training/validation/test partition. Toxicity columns in the wide summaries repeat peptide-level values across condition rows.

Exact positive observations are summarized by geometric mean within assay condition groups, then with equal group weights within each species, endpoint and class. Unknown strain identities stay separately scoped. Wide MIC columns use canonical MIC; other endpoints remain separate. Single censored observations retain their bounds; mixed exact/censored, multiple censored and unresolved groups retain individual observations for analysis.

Complete exports preserve unit-table membership with UNKNOWN placeholder rows where canonical MIC groups are unavailable; the row-status file identifies these as no_eligible_canonical_mic. For point regression select training_eligible=1; for sequence models also require sequence_training_eligible=1. Then apply sequence, condition and evidence-quality criteria appropriate to the research task.

Legacy single-row summaries

Historical summaries prioritize generic or standard-MHB source columns and use the geometric mean of exact positive values where applicable. The legacy “standard” label describes that priority rule; use current condition classes for medium-specific analysis. Mixed-direction bounds retain their unresolved state. Original M4 cells, matching-condition inoculum and measurement records remain available for reproducibility.

Values and filtering

Missing values

NR means not reported. Empty source fields are labelled “Empty in source.” Absence from the selected unit dataset is shown separately. Preserve these states as missing data; a measured zero is a distinct numerical observation.

Censored concentrations

MIC, MBC and toxicity values retain source symbols such as >128, >=64 and <0.5. Preserve their direction in analysis.

Numeric filters

Ranges use exact values by default. “Include reported bounds” compares the reported boundary with the selected range while preserving its censoring status. An organism or host filter without a range selects records with numerical evidence under this rule.

Structures and depictions

Literature-reported SMILES

smiles in CSV downloads and peptide.smiles_reported in the detail API contain the SMILES supplied by the original publication. Missing source values remain empty or NR. The has_smiles search filter selects the presence or absence of this reported field.

Reading a depiction

Two-dimensional images are prepared from curated structural definitions and may show a selected variant or fragment. They complement the reported sequence and molecular annotations. The public SMILES field preserves the literature value independently of the image. Monoisotopic exact mass and average molar mass are separate properties; activity values follow their source-unit records.

Field dictionary

pep_id
A literature-specific entity identifier, such as AS0170-P2. Verified mappings from the retired DB0001_P1 namespace redirect to current records.
sequence / complete_sequence
Source sequence fields with original residue and modification notation. Copy and export retain the original text.
n_terminus / c_terminus / complexity
Source annotations of termini and entity type, including the published “not_reported” category.
dup_group_id / split_group_id
Grouping labels derived from a case-insensitive sequence hash where sequence is known; unknown sequences use entity identity for the split group. See training partition rules.
MIC / MBC
Reported inhibitory / bactericidal concentrations. Current MIC summaries separate condition classes and endpoints. API v1 retains legacy single-row fields; MBC records retain source conditions.
HC50 / IC50
Reported hemolysis / cell-response endpoint concentrations, associated with the stated erythrocyte source or cell line.
condition_fingerprint / inoculum
Condition and inoculum text associated with a reported value. Current summaries link explicit source measurements and detailed assay fields; legacy simplified-cell provenance records source core values. Extended-set aggregation records include measurement or safety IDs and individual source conditions, including salt concentrations.

Source evidence and summary membership

Censoring and toxicity source files preserve supplied observations and their original units. They cover source evidence broadly; current condition-summary membership separately records which observations contribute to each numeric result. Source toxicity files lack a selected-record flag. censored_conflict marks mixed-direction bounds requiring source-level interpretation.
